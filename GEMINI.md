# Rules and Restrictions

## Git and GitHub Actions

* **বাংলা:** ব্যবহারকারীর সরাসরি এবং স্পষ্ট নির্দেশনা ছাড়া কোনো প্রকার `git push`, `git pull`, `git publish`, বা GitHub সংক্রান্ত action/command (যেমন branch push, PR create, npm/package publish, release) রান করা যাবে না।
* **English:** NEVER execute `git push`, `git pull`, `npm publish`, `gh` cli publish, or any other git/GitHub push, pull, or publishing command unless the user explicitly instructs you to do so.
